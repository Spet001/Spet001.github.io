About Eduardo Gelain

Software & Game Engineer

Handle: SpetDev / Spet001

Location: Brazil (Remote Worldwide)

I am a versatile software and game engineer with a strong passion for low-level mechanics, memory manipulation, and commercial game engine architectures. My journey bridges the gap between high-level gameplay engineering in Unity and C#, and low-level binary analysis in C++ and x86/x64 assembly.

Beyond building standalone games like Outcaster and contributing QA deductive code analysis to Sparky Rush on Steam, I conduct active research in reverse engineering proprietary game systems. This includes breaking through UWP and GDK sandbox restrictions, analyzing virtual machine bytecode dispatchers (such as Call of Duty's GSC engine), and building zero-dependency runtime memory injectors.
