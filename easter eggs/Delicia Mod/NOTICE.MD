## 1. Sobre o Mod / About the WAD (`doom2.WAD`)

**PT-BR:**
O arquivo `doom2.WAD` presente neste diretório é uma **Total Conversion (TC)** não-comercial e feita de fã (*fan-made*), criada como paródia/homenagem utilizando assets de áudio, gráficos e referências ao meme brasileiro **"Pai de Família" (Jailson Mendes)**.

Por se tratar de um WAD standalone construído sobre a estrutura base do *DOOM II: Hell on Earth*, este arquivo **pode conter assets originais (mapas, texturas, sprites, lumps de paleta, sons e estruturas de dados) protegidos por direitos autorais da id Software LLC / ZeniMax Media Inc.**

Este projeto é disponibilizado estritamente para fins de preservação histórica de portfólio, entretenimento e demonstração técnica, **sem qualquer finalidade comercial ou lucrativa**.

---

**EN:**
The `doom2.WAD` file in this directory is a non-commercial, fan-made **Total Conversion (TC)** mod featuring custom graphics, audio, and sprites based on the Brazilian **"Pai de Família" (Jailson Mendes)** internet meme.

Because this standalone WAD was built upon the base structure of *DOOM II: Hell on Earth*, it **may contain original game assets (maps, textures, sprites, palettes, sound effects, and data lumps) copyrighted by id Software LLC / ZeniMax Media Inc.**

This mod is hosted strictly for non-commercial, educational, and portfolio preservation purposes under fair use / fan-modding tradition.
